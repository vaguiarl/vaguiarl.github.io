# Victor H. Aguiar — Academic Website

A responsive academic portfolio for Victor H. Aguiar, built with React, TypeScript, and Vite and configured for GitHub Pages.

Live site: [vaguiarl.github.io](https://vaguiarl.github.io/)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Pushing `main` deploys the contents of `dist/` to GitHub Pages through the included workflow.

## Updating content

Research, teaching, biography, coauthor, and contact content lives in `src/App.tsx`. The visual system lives in `src/styles.css`.

The portrait was supplied by Victor Aguiar.
